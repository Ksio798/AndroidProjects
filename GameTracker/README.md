Game Tracker

ФИО: Пташков Александр Сергеевич 
Группа: Б9124-09.03.03пикд

Тема приложения

Game Tracker – офлайн-приложение для просмотра и отслеживания статусов прохождения видеоигр.

Функциональные возможности

Просмотр списка видеоигр с названием, жанром и годом выпуска.

Поиск игр по названию без учёта регистра.

Фильтрация по статусам: «Все», «Запланировано», «В процессе», «Пройдено».

Изменение статуса игры с автоматическим обновлением интерфейса.

Отображение статистики по коллекции.

Сообщение «Ничего не найдено» при отсутствии результатов.
