## Описание приложения

Starships – мобильное приложение для просмотра космических кораблей из вселенной Star Wars, разработанное на языке Kotlin с использованием Jetpack Compose.

Проект продолжает приложение из домашнего задания № 3. Добавлены внедрение зависимостей через Hilt и хранение избранных кораблей в локальной базе данных Room.

Приложение позволяет просматривать список кораблей, искать их по названию или модели, открывать подробную информацию и сохранять корабли в избранное.

## Используемый API

Приложение использует SWAPI – Star Wars API. Выбранный ресурс – Starships.

API предоставляет сведения о названии, модели, производителе, классе и характеристиках космических кораблей.

Базовый адрес – https://swapi.dev/api/

- `GET /starships/?page=1` – получение списка кораблей.
- `GET /starships/?search=Falcon&page=1` – поиск кораблей.
- `GET /starships/{id}/` – получение подробной информации о корабле.

API-ключ и авторизация не требуются.

## Функциональные возможности

- Просмотр списка кораблей с указанием названия, модели и класса.
- Поиск кораблей по названию или модели.
- Переключение страниц списка и результатов поиска.
- Просмотр подробной информации о выбранном корабле.
- Добавление кораблей в избранное на экране подробностей.
- Просмотр избранного на отдельном экране.
- Удаление кораблей из избранного на экране подробностей или в списке избранного.
- Сохранение избранного после закрытия и перезапуска приложения.
- Просмотр сохранённого списка избранного без интернета.
- Отображение состояний Loading, Error, Empty и Success, повтор загрузки после ошибки.

## Хранение данных в Room

Выбранный сценарий – избранное, Favourites.

База данных `starships.db` содержит одну таблицу `favorite_starships`.

| Поле | Тип | Назначение |
|---|---|---|
| `id` | String | идентификатор корабля, первичный ключ |
| `name` | String | название корабля |
| `model` | String | модель |
| `manufacturer` | String | производитель |
| `starshipClass` | String | класс корабля |

При добавлении корабля в избранное его данные записываются в Room. При удалении соответствующая запись удаляется из таблицы. Изменения таблицы передаются интерфейсу через Flow, и список автоматически обновляется.

Операция переключения избранного выполняется в транзакции. Первичный ключ предотвращает появление нескольких записей одного корабля.

Избранное сохраняется после перезапуска приложения. Очистка данных приложения или его удаление удаляет локальную базу.

Список избранного доступен без интернета. Экран подробностей получает данные из SWAPI и требует подключения к сети.

Схема первой версии базы хранится в `app/schemas/com.example.starships.data.local.StarshipsDatabase/1.json`.
